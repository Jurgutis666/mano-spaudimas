# Mano Spaudimas (Blood Pressure Tracker)

A blood pressure tracking app built with React. (Work in progress)

## About
Personal project for tracking blood pressure measurements.
Currently in early development stage.

## Tech Stack
- React
- Vite
- CSS

## Current Features
- Add blood pressure measurements via form
- Display list of recorded measurements
- Component-based architecture (MeasurementForm, MeasurementList)
